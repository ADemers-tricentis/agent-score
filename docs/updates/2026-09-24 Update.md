## Key Discussion Points
1. Tosca login/invite issue
   - Speaker A troubleshooting a colleague's invite - user shows as a member but hitting a 403 error when signing into the Tosca dev tenant
   - Not resolved on the call; Speaker A will investigate further later
2. Per-agent band settings
   - Speaker B implemented a change (raised by Speaker A previously) so band/threshold settings can be set per agent
   - Defaults come from the profile, but can be overridden in the back office or by the end user in agent settings
3. Consent management feature
   - Speaker B demoed a new "Consent" tab under Users: admins can upload a new consent document version, and the system tracks who has and hasn't accepted it
   - Demoed on staging in the East-1 region; West region doesn't have the file yet
   - Found a bug during the demo: uploading a new document version didn't properly reset acceptance status, so it needs a fix
   - Proposed approach: give the client back-office access so they can manage uploads and view acceptance status themselves
4. On-prem consent tracking
   - Open question: for on-prem/containerized deployments, how would Tricentis see or verify that a user accepted the AI terms and beta agreement (e.g., for Agent Score) before login
   - Tension noted: the client doesn't want data leaving the license file/on-prem environment, but Tricentis needs acceptance data to verify compliance
   - Legal's specific requirements are still unclear to both speakers
5. Client environment/network capabilities
   - Unclear whether the client's on-prem environment can "phone home" at all, or is fully isolated
   - Speaker A has a meeting with the client on Monday to clarify their deployment setup and what's technically possible
6. Credit feature and security review
   - "Credit" feature was deployed to staging but not yet tested (Speaker B ran out of time this morning)
   - Security review ("Omen") won't start until the middle of next week, meaning production release likely won't happen before Speaker B leaves for vacation
   - Speaker A plans to spend the next two weeks trying to clear non-development blockers (ProdSec, legal) so things are ready to go when Speaker B returns

## Decisions Made
- Band/threshold settings will be configurable per agent, with defaults from the profile and overrides available in the back office and to individual users
- Consent management will give the client back-office access to upload documents and view acceptance status themselves, rather than Tricentis managing it centrally
