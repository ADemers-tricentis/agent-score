# Competitor Intel - 2026-10-14

_Dedup baseline: 2026-10-12 digest. Checked all 12 tracked/watch-list competitors across the updates bucket (web search plus GitHub releases for Langfuse, Phoenix, Opik, DeepEval). Only Langfuse, Arize AI, Comet / Opik and Confident AI / DeepEval had new, sourced findings. Braintrust, Galileo, LangSmith, W&B Weave, Arato, Patronus AI, int4 TrustGate and Maxim AI turned up nothing new and independently verifiable, and are omitted. Customer-sentiment and usage buckets produced nothing new beyond the baseline._

## Langfuse
- **Update:** Three releases since the last digest: v4.57.0 (Oct 12) adds API key expiration on the gateway and graduates decision-model evaluators; v4.58.0 (Oct 13) lets Topics run on a project's own LLM connections; v4.59.0 (Oct 14) adds a Topics trace filter/search bar, an audit_logs table with a ClickHouse relay, and makes the redesigned session view default. v4.59.0 also notes JS v6 / Python v5 SDK major releases are being prepared. ([v4.59.0 and prior releases](https://github.com/langfuse/langfuse/releases))

## Arize AI (Phoenix + Arize AX)
- **Update:** Phoenix shipped v20.21.1 (Oct 12), v20.21.2 (Oct 13) and v20.21.3 (Oct 14) after v20.21.0; all maintenance (span ingestion reliability, experiment latency fix on PostgreSQL, docs link fixes). ([Phoenix releases](https://github.com/Arize-ai/phoenix/releases))

## Comet / Opik
- **Update:** Opik 2.2.98 to 2.2.100 (Oct 12-14): higher default max_tokens for Claude judges that use extended thinking, fixed double-counting of cache tokens for Anthropic/Bedrock LangChain usage, triggered alerts now publish to AWS EventBridge, and MCP server instructions plus deferred tool listings now show in the server breakdown view. ([Opik releases](https://github.com/comet-ml/opik/releases))

## Confident AI / DeepEval
- **Update:** DeepEval python-v4.2.4 (Sep 22) adds opt-in experimental support for TypeSafe AI's Jev model and "classifiers" that return one label from a closed set (e.g. `RefusalClassifier`) instead of a 0-1 score. Python 4.2.0 (Aug 24) added voice features, MCP server support and standardized metric scores so higher is better. ([DeepEval releases](https://github.com/confident-ai/deepeval/releases))
