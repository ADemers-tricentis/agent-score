# Competitor Intel - 2026-10-13

_Dedup baseline: 2026-10-12 digest. Checked all 12 tracked/watch-list competitors (Langfuse, Braintrust, Arize AI, Galileo, LangSmith, W&B Weave, Arato, Patronus AI, int4 TrustGate, Comet/Opik, Maxim AI, Confident AI/DeepEval). Findings this run come from OSS GitHub release pages; web searches for customer praise and usage returned nothing new and verifiable. Competitors not listed below had nothing new._

## Langfuse
- **Update:** Langfuse v4.57.0 (Oct 12) adds API key expiration to the gateway, graduates decision model evaluators out of experimental, and extracts inline media from raw OTEL documents; v4.58.0 (Oct 13) adds per-project trace idle time and an upload pool for media. ([v4.57.0/v4.58.0 releases](https://github.com/langfuse/langfuse/releases))

## Arize AI (Phoenix + Arize AX)
- **Update:** Phoenix v20.21.1 (Oct 12) fixes span ingestion reliability and lets TraceDataset accept empty dataframes. ([GitHub releases](https://github.com/Arize-ai/phoenix/releases))

## Comet / Opik
- **Update:** Opik 2.2.97 to 2.2.99 (Oct 12-13) ship triggered alerts published to AWS EventBridge, MCP server instruction visibility in breakdowns, and Vertex AI model registry resolution. ([GitHub releases](https://github.com/comet-ml/opik/releases))

## Confident AI / DeepEval
- **Update:** DeepEval 4.2.4 (Sep 22) adds opt-in experimental support for Jev, TypeSafe AI's model for closed-ended eval decisions, plus classifiers that return one label from a closed set instead of a 0-1 score. ([GitHub releases](https://github.com/confident-ai/deepeval/releases))
