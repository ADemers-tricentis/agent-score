## Langfuse
- **Update (2026-11-16):** Langfuse Cloud becomes v4-only today: the legacy batch ingestion API used by Python SDK v2 and JS/TS SDK v3 (and earlier) is removed, and trace-level evaluators stop producing results, so projects must be on the GA SDK majors. Self-hosted v3 is not bound by the date. ([Langfuse compatibility page](https://langfuse.com/docs/compatibility))

## Comet / Opik
- **Update (2026-11-16):** 2.2.144 starts building runtime guardrails: guardrail validation and policy API contracts (stubbed to return 501), a guardrail policies service behind a toggle, execution of guardrail rules on the Opik backend, and a guardrail policies page in the UI. It also enforces the Free plan span quota on OpenTelemetry trace ingestion. ([Opik 2.2.144](https://github.com/comet-ml/opik/releases/tag/2.2.144))

## So what for AgentScore
Opik is moving into runtime guardrails (policies, inline validation), the same space where Galileo's Protect already competes and which our Capability Gaps list as Gap 5. It is still stubbed, so no change in priority yet, but it is a second OSS-priced entrant to watch before we revisit that decision.
