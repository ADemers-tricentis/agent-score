# Competitor Intel — 2026-10-08

_Dedup baseline: 2026-10-07 digest. Checked all 12 tracked/watch-list competitors (Langfuse, Braintrust, Arize AI, Galileo, LangSmith, W&B Weave, Arato, Patronus AI, int4 TrustGate, Comet/Opik, Maxim AI, Confident AI/DeepEval) across all three buckets. A few items below (Langfuse's Helm chart release, Patronus's TrueFoundry integration guide, DeepEval's Thoughtworks Radar mention) are older than the usual 24-48h window but had not surfaced in any prior digest, so they're reported here per the skill's "new to this digest" rule rather than dropped as stale._

## Langfuse
- **Update:** Helm chart repo `langfuse-k8s` shipped v2.0.0 (Aug 18) removing all Bitnami-dependency defaults and swapping bundled Postgres/Redis/ClickHouse for OSS-licensed alternatives, followed by a v2.0.1 patch (Aug 24). ([GitHub releases](https://github.com/langfuse/langfuse-k8s/releases))
- **Customers love:** A separate Gartner Peer Insights review titled "centralized LLM trace visualization improved debugging, but slow bulk queries persist" contributes to a 4.6/5 average across 5 ratings. ([Gartner Reviews](https://www.gartner.com/reviews/product/langfuse-658437652))
- **Using it for:** SumUp built an AI support-deflection workflow on Langfuse that routes roughly half of support conversations to AI, saving ~30% of external BPO cost. ([Langfuse](https://langfuse.com/users))

## Braintrust
- **Using it for:** CrewAI's docs added a dedicated Braintrust integration guide (OpenTelemetry-based tracing plus the Eval SDK for offline prompt/model comparisons); separately, third-party coverage of Notion's rollout credits embedding evals into the workflow across 70 engineers with taking the team from fixing ~3 AI issues/day to ~30/day. ([CrewAI docs](https://docs.crewai.com/v1.15.14/en/observability/braintrust), [Voiceflow](https://www.voiceflow.com/blog/what-is-braintrust))

## Arize AI
- **Using it for:** TheFork's customer story describes using Arize AX to trace/evaluate production AI systems, catching regressions and governing costs before they reach production ("intervene before an issue reached production"). ([Arize](https://arize.com/customers))

## Galileo
- **Using it for:** A Galileo case study describes an unnamed fintech/investment-accounting platform that replaced manual log review with Galileo for evaluation and monitoring, citing a +30% efficiency gain and MTTD/MTTR dropping from days to minutes. ([Galileo](https://galileo.ai/case-studies/galileo-helps-a-leading-fintech-solution-reduce-mean-time-to-detect-from-days-to-minutes))

## LangSmith
- **Update:** LangChain merged its two usage-billing units (LCU at $1.50, LSU at $1.00) into a single "LangChain Standard Unit" priced at $1.00 (reported Oct 2, 2026) - not necessarily rate-neutral, so existing customers need to recompute spend. ([PricingSaaS](https://pricingsaas.com/news/article/langchain-merges-langsmith-lcu-and-lsu-into-one-1-00-standard-unit))

## Patronus AI
- **Using it for:** TrueFoundry's integration guide shows Patronus wired into TrueFoundry's AI Gateway to enforce consistent prompt-injection/PII/toxicity/hallucination checks across multiple model providers routed through one gateway (guide dated ~April-May 2026, not previously reported). ([TrueFoundry](https://www.truefoundry.com/blog/patronus-integration-with-truefoundrys-ai-gateway))

## Comet / Opik
- **Update:** A rapid string of GitHub releases (Oct 1-8, v2.2.87→v2.2.95) added native Ollama SDK integration, a new "free-form SQL" post-run check for evaluations (off/audit/enforce modes), Gemini 3.1 Flash Lite reasoning-effort support, and migrated in-app setup snippets off gpt-3.5-turbo ahead of its Oct 23 retirement. ([GitHub releases](https://github.com/comet-ml/opik/releases))
- **Using it for:** Opik shipped a dedicated tracing integration for Oracle's Agent Spec (an open agent configuration language) - an instrumentor tracing LLM calls, tool calls, and intermediate steps across runtimes/adapters, with an option to mask sensitive data. ([Comet docs](https://www.comet.com/docs/opik/integrations/agentspec))

## Maxim AI
- **Customers love:** New G2 reviews (4.8/5, 3 reviews) call out launching agent evaluation "without instrumenting the agentic platform," real-time usage monitoring as the most-liked feature, and the annotation feature for cutting manual/Python scripting work. ([G2](https://www.g2.com/products/maxim-ai/reviews))
- **Using it for:** A new voice-agent workflow lets teams connect a real phone number and run a simulator against thousands of real-life call scenarios, scoring metrics like talk ratio and average call duration - extending Maxim's simulation capability from text-based customer-support scenarios into voice. ([Maxim changelog](https://changelog.getmaxim.ai/voice-agent-workflows-and-simulation-323552))

## Confident AI / DeepEval
- **Update:** DeepEval v4.2.4 ("Introducing Jev") added opt-in experimental support for TypeSafe AI's "Jev" model as a decision-point judge, plus new categorical LLM-as-judge classifiers such as RefusalClassifier (complied / refused / partial_refusal verdicts). ([GitHub releases](https://github.com/confident-ai/deepeval/releases), [DeepEval](https://deepeval.com/integrations/models/typesafe-ai))
- **Using it for:** Thoughtworks' Technology Radar (April 2026 entry) flags DeepEval for having expanded to support complex agentic workflows and multi-turn conversational systems, beyond simple single-turn LLM testing. ([Thoughtworks](https://www.thoughtworks.com/radar/languages-and-frameworks/deepeval))

## So what for AgentScore
Maxim's new voice-agent simulation workflow - scoring real phone-call scenarios for talk ratio and call duration - shows the simulation-first competitors (Arato, Patronus, Maxim) extending the exact capability our own report flags as Gap #4 into a new modality, widening that gap rather than holding steady. Nothing else today moves the needle: LangSmith's billing-unit merger is a pricing mechanic rather than a packaging change that reshapes the comparison, and Comet/Opik's release cadence is routine eval tooling rather than a new category.
