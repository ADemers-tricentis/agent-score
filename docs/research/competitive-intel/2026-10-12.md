# Competitor Intel, week of 2026-10-12

_Coverage: Monday 2026-10-12 through Sunday 2026-10-18. Consolidated from daily sweeps on Oct 12, Oct 13, Oct 14, Oct 15, and Oct 16. Compared against weekly digests through 2026-10-05. Customer-praise and usage searches found nothing new. Braintrust, Galileo, LangSmith, W&B Weave, Arato, Patronus AI, int4 TrustGate, and Maxim AI had no verifiable product news and are omitted. DeepEval's Jev release (Sep 22) was repeated in several daily files and is not listed again._

## Langfuse
- **Update (2026-10-12):** v4.57.0 through v4.62.0 (Oct 12-16) add gateway API-key expiration, decision-model evaluators leaving experimental, inline media extracted from raw OTEL, per-project trace idle time, Topics running on a project's own LLM connection, a Topics trace search bar, an audit log relayed to ClickHouse, and the redesigned session view as the default. The same range adds org-level LLM connections, a skills tab with skill-version views on traces, prompt cache hit rate, gateway routing by connection slug, and a self-hosted outbound host allowlist. ([GitHub releases](https://github.com/langfuse/langfuse/releases))

## Arize AI (Phoenix + Arize AX)
- **Update (2026-10-15):** Phoenix v20.22.0 adds Meta muse-wonder-1.0 and gemini-4-argon to the playground, keeps SameSite=Strict cookies through OAuth sign-in, and documents tracing for Claude Managed Agents. v20.23.0 (Oct 16) exports server logs over OTLP and documents Atomic Agents tracing. Patch releases between v20.21.0 and v20.21.4 were ingestion, latency, and docs fixes and are omitted. ([GitHub releases](https://github.com/Arize-ai/phoenix/releases))

## Comet/Opik
- **Update (2026-10-12):** Opik 2.2.97 through 2.2.103 (Oct 12-16) publish triggered alerts to AWS EventBridge (including an opt-in Helm setting), show MCP server instructions in the breakdown view, resolve models through the Vertex AI registry, raise the default max tokens for Claude judges that use extended thinking, stop double-counting Anthropic and Bedrock cache tokens, add a model catalog with per-model parameters, add a native Together AI SDK integration, and fix Google ADK span tracking. ([GitHub releases](https://github.com/comet-ml/opik/releases))

## Confident AI/DeepEval
- **Update (2026-10-16):** `deepeval setup` is an evaluation wizard. The same release adds a sound-glitch metric, audio support in ConversationalGEval, and Claude Opus 5.5 in the Anthropic model registry. The transcription-accuracy metric itself landed the previous week. ([GitHub releases](https://github.com/confident-ai/deepeval/releases))
