# Competitor Intel - 2026-10-22

_Dedup baseline: 2026-10-12 digest. Checked all 12 tracked/watch-list competitors for product updates. Customer-praise and usage searches (G2, Reddit, HN, case studies) did not surface anything new and independently verifiable, so only Update bullets appear. Langfuse, Arize AI, Comet/Opik and Confident AI/DeepEval had new findings; Braintrust, Galileo, LangSmith, W&B Weave, Arato, Patronus AI, int4 TrustGate and Maxim AI had nothing newer than prior coverage and are omitted. Release dates on GitHub pages are shown without years; they were read as 2026 releases._

## Langfuse
- **Update:** Shipped v4.65.0 through v4.67.0 (Oct 20-21): non-blocking clustering and better naming for Topics, a self-hosted "None" ingestion mode and gateway key filters for the AI gateway, a stabilized skills API with MCP access, and simplified CLI install for skills. ([GitHub releases](https://github.com/langfuse/langfuse/releases))

([GitHub releases](https://github.com/Arize-ai/phoenix/releases))

## Comet/Opik

([GitHub releases](https://github.com/comet-ml/opik/releases))

## Confident AI/DeepEval
