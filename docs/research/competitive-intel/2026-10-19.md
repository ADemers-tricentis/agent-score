## Langfuse
- **Update (2026-10-16):** v4.63.0 through v4.70.0 (Oct 16-24) rename the assistant to Halo, add topic run cost, ship skill management as a public preview with MCP access and managed skills, separate AI Gateway keys from organization API keys (including member-created and service-account keys), and add a recovery path back to the v4 experience. Later tags in the range add non-blocking clustering for large Topics volumes, a self-hosted "None" ingestion mode, a guided gateway setup, Topics rules written against the trace transcript with treemap and grid views, an outbound allowlist for blob storage, a `runBatchEvaluation` MCP tool, a read-only Topics API, Cmd+K navigation to prompts, datasets, queues, and evaluators, and a fix that requires secrets again when webhook or PostHog destinations change. ([GitHub releases](https://github.com/langfuse/langfuse/releases))

## Arize AI (Phoenix + Arize AX)
- **Update (2026-10-21):** Phoenix v20.24.0 reports uncaught frontend errors to the server log and pins dependencies to exclude compromised litellm 1.107.0. phoenix-evals v2.7.0 the same day runs classification evaluators on AI SDK models. v20.25.0 (Oct 22) scaffolds a managed-agents issue-to-PR factory. v20.26.0 (Oct 23) and v20.26.1 (Oct 25) link factory session IDs to the Claude Console, add `service.version` on the server's OpenTelemetry resource, and document Microsoft Agent Framework tracing. phoenix-evals v3.9.3 (Oct 22) and v3.9.4 (Oct 24) keep the litellm exclusion, require certifi 2026.10.18, and fix prompt-template format overrides. ([GitHub releases](https://github.com/Arize-ai/phoenix/releases))

## Comet/Opik
- **Update (2026-10-19):** Opik 2.2.104 through 2.2.119 (Oct 19-23) add Agent Insights with node-to-span navigation, span pricing for every LiteLLM provider, a native Cohere SDK integration, OpenAI Decisions API tracing, and test-suite version viewing without a restore. The same range routes OTel traces to a project via `opik.project_name`, can hide internal traces in threads, fails a test-suite judge over to the next provider, adds Redis Sentinel, a sidebar editor for online evaluation rules, GPT 5.5 as the default online-eval model for OpenAI and OpenRouter, and server-side start/stop for playground dataset experiments. nginx rules for `/v1/internal` were tightened. ([GitHub releases](https://github.com/comet-ml/opik/releases))
