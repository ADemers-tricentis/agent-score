## So what for AgentScore
Cisco Tokenomics and Opik's Claude Code plugin both treat a coding agent as something to track. Tokenomics measures spend and adoption. Opik turns the session into traces. Neither scores the agent's quality. On price, LangSmith roughly doubled trace rates in July and W&B raised its Evals tier 140% on Sep 8, while AgentScore still has no public price. Maxim's retroactive evals on logs it already stored are the closest move to grading traces that were collected earlier, and they still require Maxim's SDK. DeepEval 4.0 puts an eval-retry loop inside Claude Code, Codex, and Cursor.
