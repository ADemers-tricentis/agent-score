## Braintrust
- **Update:** Shipped "Nitro," a new asynchronous query execution engine for Brainstore aimed at faster debugging queries over production agent traces (Sept 24, 2026). ([Braintrust blog](https://www.braintrust.dev/blog/nitro))

## Galileo (now under Cisco/Splunk)
- **Update:** At Splunk .conf26 (week of Sept 15, 2026), Cisco launched "Tokenomics" inside Splunk Agent Observability (the Galileo-derived product) - tracking and forecasting token spend, adoption, and productivity for AI coding agents (Claude Code, Codex, Cursor) across a team, using Cisco's Deep Time Series Model to project billing before a cycle ends. ([MSSP Alert](https://www.msspalert.com/brief/cisco-enhances-splunk-observability-for-ai-token-usage-tracking-1), [Cisco newsroom](https://newsroom.cisco.com/c/r/newsroom/en/us/a/y2026/m09/cisco-delivers-trusted-ai-at-scale-through-new-splunk-advancements.html))

## Weights & Biases Weave
- **Update:** W&B Server 0.85.0 (Sept 23, 2026) made Weave calls and agent spans link to each other bidirectionally, letting users jump between a call and the agent span that produced it. ([wandb/server release](https://github.com/wandb/server/releases/tag/0.85.0))

## Comet / Opik
- **Update:** Shipped an official Claude Code plugin and MCP server (`comet-ml/opik-claude-code-plugin`, active Sept 21-25, 2026) that logs Claude Code sessions to Opik as traces - each conversation turn becomes a trace, tool calls/thoughts/responses become spans, and subagent calls nest under the parent Task span - plus a companion "agent skills" pack (`/opik`, `/opik-connect`, `/instrument`, `/agent-ops`, `/evaluation`) and an agent-reviewer skill that checks agent code for idempotence, retry safety, and observability hooks. ([GitHub](https://github.com/comet-ml/opik-claude-code-plugin), [Opik docs](https://www.comet.com/docs/opik/integrations/claude-code))

## So what for AgentScore
Two competitors this week productized "observe/grade your own AI coding agent" as a first-class surface - Cisco/Splunk's Tokenomics (cost/adoption tracking for Claude Code, Codex, Cursor usage) and Opik's Claude-Code-session-to-trace plugin (turning a coding session itself into an OTel-style trace for their own eval pipeline). That's the same move AgentScore already makes internally via `export_claude_session.py` dogfooding, but neither competitor frames it as agent *quality* grading - Splunk's angle is cost/spend, Opik's is observability/tracing, not a scored verdict. It's a data point that "AI coding agent as tracked agent" is becoming a recognized category worth watching, not yet a capability gap - AgentScore's zero-setup scoring story remains undifferentiated-from-below here since neither ships a ship/don't-ship verdict on the coding agent's own behavior.
