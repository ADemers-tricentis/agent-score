# Competitor Intel — 2026-10-11

_Dedup baseline: 2026-10-10 digest. Checked all 12 tracked/watch-list competitors (Langfuse, Braintrust, Arize AI, Galileo, LangSmith, W&B Weave, Arato, Patronus AI, int4 TrustGate, Comet/Opik, Maxim AI, Confident AI/DeepEval) across all three buckets. Arato, Patronus AI, and int4 TrustGate had nothing new survive sourcing/dedup and are omitted below._

## Langfuse
- **Update:** Langfuse server v4.56.0 (Oct 9, 2026) added spend alerts for orgs billed through ClickHouse, a design-system code viewer, and a new onboarding survey. ([GitHub release](https://github.com/langfuse/langfuse/releases/tag/v4.56.0))
- **Customers love:** Gartner Peer Insights reviewers single out centralized trace visualization for debugging multi-step pipelines and prompt versioning over manual prompt management, though one flags slow bulk queries. ([Gartner](https://www.gartner.com/reviews/product/langfuse-658437652))
- **Using it for:** Intuit presented an LLM-observability case study pairing Langfuse with ClickHouse at ClickHouse's "Open House 2026" event. ([ClickHouse](https://clickhouse.com/videos/openhouse-building-with-langfuse-intuit))

## Braintrust
- **Update:** Braintrust shipped a dedicated Microsoft Agent Framework (.NET) integration, tracing agent runs, model calls, and tool executions via a `Braintrust.Sdk.AgentFramework` middleware package. ([Braintrust docs](https://www.braintrust.dev/docs/integrations/agent-frameworks/microsoft-agent-framework))
- **Customers love:** G2 reviewers call it "remarkably fast and reliable for prompt evaluation," citing ~2-day setup and helpful (if sometimes slow) support. ([G2](https://www.g2.com/sellers/braintrust-70da938f-eb27-4a47-ab01-a0bb5c7c9102))
- **Using it for:** Notion's AI modeling lead says its ~70-engineer team spends ~90% of its time evaluating/improving evals (vs. 10% prompting) in Braintrust, shipping frontier-model updates to production in under 24 hours. ([Braintrust](https://braintrust.dev/blog/notion))

## Arize AI
- **Update:** Phoenix (OSS) shipped v20.20.0 (Oct 9) with a Docker Sandboxes provider and new GraphQL tools on its MCP server, following v20.19.0 (Oct 1)'s new "DECISION" span kind for tracing agent decision points. ([v20.20.0](https://github.com/Arize-ai/phoenix/releases/tag/arize-phoenix-v20.20.0), [v20.19.0](https://github.com/Arize-ai/phoenix/releases/tag/arize-phoenix-v20.19.0))
- **Customers love:** G2 reviewers (4.2/5) praise offline/online evaluation features and visibility into model performance and data quality, while flagging a learning curve on integration. ([G2](https://www.g2.com/products/arize-ai/reviews_and_filters))
- **Using it for:** LG Uplus used evaluation-driven development on Arize AX to raise its AI customer-service agent accuracy from 70% to 96% across 30M subscribers, crediting visibility into intermediate agent decisions. ([Arize](https://arize.com/customers/how-lg-uplus-is-building-better-agents-with-evaluation-driven-development-and-arize-ax/))

## Galileo
- **Using it for:** Elastic's Director of Developer Relations says the company uses Galileo's evaluation platform specifically for AI agent reliability work (Galileo-produced podcast, not an independent source). ([Chain of Thought podcast](https://chainofthought.transistor.fm/episodes/the-ai-agent-trust-gap-bridging-risk-to-reliability-elastic-s-philipp-krenn))

## LangSmith
- **Update:** LangSmith's base trace pricing reportedly doubled from $2.50 to $5.00 per 1,000 runs, with Deployment moving from per-run/uptime billing to resource-based metering, as the grandfather period for existing Deployment customers ended Oct 1, 2026 (per a third-party pricing tracker - not independently confirmed on LangChain's own pricing page). ([CostBench](https://costbench.com/changelog/langsmith-price-decrease-2026-08/))
- **Customers love:** A G2 reviewer praises execution traces for letting them drill from a high-level agent run down to individual LLM calls and tool interactions, naming the LangChain/LangGraph and multi-provider integrations as what makes it fit their stack. ([G2](https://www.g2.com/survey_responses/langsmith-review-13398457))
- **Using it for:** ServiceNow uses LangSmith/LangGraph for visibility into its customer-success agents, and Vizient pairs LangGraph with LangSmith for multi-agent reliability in a healthcare-data query system. ([ServiceNow](https://blog.langchain.com/customers-servicenow), [Vizient](https://blog.langchain.com/customers-vizient))

## W&B Weave
- **Customers love:** A Canva senior MLE describes using Weave to test a feature change against different LLMs and pick one by weighing output quality against cost together (vendor-published quote, not independent review-site sentiment). ([W&B](https://cdn-assets.inwink.com/5a4c98a3-bfa0-485a-9c03-855fd27662a9/f3597745-31b8-4701-be21-6e7753cc7b27))
- **Using it for:** MasterClass uses W&B Weave to trace, monitor, and improve its AI agents, per CoreWeave's own announcements page. ([CoreWeave](https://www.coreweave.com/news-categories/company-announcements))

## Comet / Opik
- **Update:** Opik's backend added a tiered-storage policy (Oct 9) that moves cold trace/span data out of hot storage via a background job, plus new partition metrics for cold-tier bytes and TTL backlog. ([PR #8838](https://github.com/comet-ml/opik/pull/8838), [PR #8817](https://github.com/comet-ml/opik/pull/8817))
- **Customers love:** A developer switched from Braintrust to Opik specifically because Braintrust's free plan limited data retention, and praised a Comet maintainer who personally answered setup questions. ([Substack](https://opensourcedisc.substack.com/p/opensourcediscovery-99-opik))
- **Using it for:** Comet's CEO says Opik runs in production for AI teams at Uber, Netflix, Autodesk, and NatWest, closing the loop between dev-time testing and live trace data. ([Cerebral Valley](https://cerebralvalley.beehiiv.com/p/comet-is-closing-the-loop-between-production-and-development-for-ai-agents))

## Maxim AI
- **Customers love:** A verified G2 reviewer specifically calls out Maxim's dataset annotation feature and Prompt IDE, saying setup was simple. ([G2](https://www.g2.com/products/maxim-ai/reviews))
- **Using it for:** Maxim's published case content says Clinc cut hallucinations in its conversational banking agents by 72% using Maxim's simulation/eval workflow (vendor-reported), and lists Comm100 as using Maxim to prototype and validate support agents. ([Maxim](https://www.getmaxim.ai/articles/how-to-build-reliable-ai-agents-the-definitive-guide-for-2025-with-maxim-ai))

## Confident AI / DeepEval
- **Update:** DeepEval merged a new Transcription Accuracy metric for voice/audio agent evaluation (Oct 5) and added dataset-version tracking to test runs (Oct 9). ([PR #3414](https://github.com/confident-ai/deepeval/pull/3414), [PR #3417](https://github.com/confident-ai/deepeval/pull/3417))
- **Customers love:** A G2 reviewer praises concrete, measurable checks for data leakage, contextual relevancy, and noise in results, while noting it's challenging for non-technical users. ([G2](https://www.g2.com/products/confident-ai/reviews_and_filters))
