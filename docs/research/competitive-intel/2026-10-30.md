## Arize AI (Phoenix + Arize AX)
- **Update (2026-10-30):** Phoenix v21.0.0 turns authentication on by default (no PHOENIX_SECRET needed), adds DECISION and AGENT annotation kinds across the Python and TypeScript clients and the px CLI, and fetches model cost manifests at runtime; a migration guide is linked. ([arize-phoenix v21.0.0](https://github.com/Arize-ai/phoenix/releases))

## Langfuse
- **Update (2026-10-29):** v4.72.0 attributes AI Gateway spans to their gateway API key and service, adds an AI Gateway analytics tab and onboarding, sends alerts and prompt changes to PagerDuty, and adds trace-level filter conditions for evals. ([v4.72.0](https://github.com/langfuse/langfuse/releases/tag/v4.72.0))

## Comet/Opik
- **Update (2026-10-30):** Opik 2.2.134 through 2.2.137 add faster thread search that returns matching threads with all their traces, synced model prices, a Pixeltable integration, and backend tables for two-lane session analysis. ([2.2.137](https://github.com/comet-ml/opik/releases/tag/2.2.137))

## So what for AgentScore
Phoenix defaulting to authenticated deployments and adding DECISION and AGENT annotation kinds moves open-source tracing toward agent-level judgment records, which overlaps AgentScore's agent-scoring angle. Langfuse and Opik continue to invest in gateway and session-level analysis, so trace-to-eval workflows keep converging across the field.
