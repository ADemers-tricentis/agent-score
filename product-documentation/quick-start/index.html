Agent Score

Quick start

Connect your coding agent, name the agent you want scored, and check that its traces arrived. Open Agent Score at agent-score.ai.tricentis.com.

  1. Sign in to Tosca Cloud Agent Score uses your Tosca Cloud account. If you do not have one yet, sign up for a Tosca Cloud trial first, then sign in. Signing in creates your workspace. Everyone who signs in from that Tosca Cloud tenant shares it. Note: Agent Score is currently unavailable for SAP tenants and organizations that have previously selected the "Block AI" flag. If your agent already runs in AI Workspace, its traces arrive when it runs. No ingest key. You can skip the rest of this page.
  2. Add Agent Score and sign in In the sidebar, open Integrations. The card at the top is Connect a coding agent (MCP). Copy the server URL whole. The part after the ? names your tenant. A client that drops it cannot sign in. Add that URL in Claude Code, Cursor, Codex, or the Claude apps. There is no API key to paste. The card shows the command or file for your client, with your URL already filled in. Your browser opens Agent Score. Sign in with your Tosca Cloud account, check the request, and click Allow. Then finish in the client:
    • Claude Code. Run /mcp, choose agent-score, then Authenticate.
    • Cursor. Open Customize, go to MCP, and sign in on agent-score.
    • Codex. Click Authenticate beside agent-score, then start a new session.
    • Claude apps. Add a custom connector named Agent Score and leave the OAuth client ID and secret empty. Click Connect. In a chat, turn Agent Score on under Connectors.
  3. Name the agent and start its traces Open the project for the agent you want scored, and ask: 
    Set this agent up to send its traces to Agent Score. Name it checkout-agent.
    checkout-agent is an example. Use the name you want that agent to keep. The coding agent creates an ingest key, writes the exporter settings into an environment file that version control ignores, and sets OTEL_SERVICE_NAME to that name. Agent Score files the traces under it. Restart the agent and run it once, on a real request.
  4. Check that the traces arrived Ask: 
    Use agent-score to check my agent connection.
    The answer lists your ingest keys and whether traces for that name arrived in the last hour.
  5. Read your scorecard After about 20 traces, scoring starts on its own. Open the agent to see a 0-100 score and a ship / review / don't-ship recommendation, with the evidence behind every number.
The ingest key is shown onceHave the agent write the key to an environment file that version control ignores. Keep it out of source, chat, and logs. If that reply is lost, rotate the key on Integrations. The old secret cannot be shown again.
Send real trafficScoring is only as honest as the traces behind it. Send real or realistic traffic, including the ordinary failures.
A change takes effect when you askYour coding agent acts as you. Starting a scoring run, publishing an eval, or deleting an agent happens immediately. Ask only for a change you want made.
